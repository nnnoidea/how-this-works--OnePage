How This Works helps a developer encountering a project for the first time understand its purpose, main capabilities, cooperation and adoption conditions. Key points are explained visually and linked to a specific source version.

## B What OnePage understanding adds
HTW connects Dify's building experience, knowledge retrieval, execution and adoption conditions. This makes it a closer fit for a first overview of the whole project. Answer goes deeper into Workflow version selection, execution and troubleshooting.

Both produced several diagrams. The meaningful difference is which questions they explain and how those questions build an overall understanding, not the diagram count.

The two page readers had different preferences. Source review found both broadly accurate. HTW used 577083 total tokens and Answer 600422, each taking about 116 seconds. Totals include cache and are not prices; external review is excluded. One run does not establish general superiority.
